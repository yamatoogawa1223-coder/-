# スーパーピクセルラン

マリオ風の横スクロール・アクションゲームです。HTML ファイル 1 枚で動きます（外部ライブラリなし）。

## 遊び方

`index.html` をブラウザで開くだけ。スマホではタッチボタンが表示されます。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ← → / A D | ◀ ▶ |
| ジャンプ（長押しで高く） | Space / ↑ / Z | A |
| ダッシュ | Shift / X | B |
| ポーズ | P / Esc | — |
| 音のオン・オフ | M | — |

## 内容

- 敵を踏んで倒す（連続で踏むと得点アップ）
- 「?」ブロックからコイン、キノコ（パワーアップで大きくなる）
- 大きい状態ならレンガを壊せる
- カメの甲羅を蹴って敵をまとめて倒す
- 中間ポイント、制限時間、コイン 100 枚で 1UP
- ゴールの旗にタッチしてお城へ入ればクリア

# 星屑の夜（弾幕シューティング）

`danmaku.html` をブラウザで開くだけで遊べる縦スクロール弾幕STGです。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | 矢印 / WASD | 画面ドラッグ |
| 低速（当たり判定表示） | Shift | 低速ボタン |
| ボム | X / B | BOMB ボタン |
| ポーズ / ミュート | P / M | — |

- ショットは自動連射、Pアイテムで最大4段階パワーアップ
- グレイズ（弾すれすれ）でスコア加算、被弾直後12フレーム以内のボムで回避（喰らいボム）
- 難易度 EASY / NORMAL / HARD、ザコ戦のあと4フェーズ（スペルカード3つ）のボス戦
