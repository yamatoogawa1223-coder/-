# スーパーピクセルラン

マリオ風の横スクロール・アクションゲームです。HTML ファイル 1 枚で動きます（外部ライブラリなし）。

## 遊び方

`index.html` をブラウザで開くだけ。スマホではタッチボタンが表示されます。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ← → / A D | ◀ ▶ |
| ジャンプ（長押しで高く） | Space / ↑ / Z | A |
| ダッシュ | Shift / X | B |
| ポーズ | P / Esc | — |
| 音のオン・オフ | M | — |

## 内容

- 敵を踏んで倒す（連続で踏むと得点アップ）
- 「?」ブロックからコイン、キノコ（パワーアップで大きくなる）
- 大きい状態ならレンガを壊せる
- カメの甲羅を蹴って敵をまとめて倒す
- 中間ポイント、制限時間、コイン 100 枚で 1UP
- ゴールの旗にタッチしてお城へ入ればクリア

# 脱出ゲーム：閉ざされた書斎

`escape.html` をブラウザで開くだけで遊べる、1 部屋の脱出ゲームです。

- ◀ ▶ で四方の壁を見回し、気になる場所をタップ／クリック
- 持ち物をタップで選択 → 使いたい場所をタップ
- 4 桁の暗証番号を見つけて、ドアを開けて脱出しよう
