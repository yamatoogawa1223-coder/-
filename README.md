# スーパーピクセルラン

マリオ風の横スクロール・アクションゲームです。HTML ファイル 1 枚で動きます（外部ライブラリなし）。

## 遊び方

`index.html` をブラウザで開くだけ。スマホではタッチボタンが表示されます。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ← → / A D | ◀ ▶ |
| ジャンプ（長押しで高く） | Space / ↑ / Z | A |
| ダッシュ | Shift / X | B |
| ポーズ | P / Esc | — |
| 音のオン・オフ | M | — |

## 内容

- 敵を踏んで倒す（連続で踏むと得点アップ）
- 「?」ブロックからコイン、キノコ（パワーアップで大きくなる）
- 大きい状態ならレンガを壊せる
- カメの甲羅を蹴って敵をまとめて倒す
- 中間ポイント、制限時間、コイン 100 枚で 1UP
- ゴールの旗にタッチしてお城へ入ればクリア

# ナイトメア・エスケープ（`nightmare.html`）

非対称対戦ホラー風の脱出サバイバル。逃走者（あなた）が殺人鬼AIから逃げながら発電機を3台直し、出口ゲートから脱出します。HTML 1 枚で動作（外部ライブラリなし）。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | WASD / 矢印 | 画面左をドラッグ |
| 行動（修理・パレット・窓・ロッカー・スキルチェック） | Space / E | 「行動」ボタン |
| ポーズ / 音 | P / M | — |

- 発電機の修理中に出る **スキルチェック** に失敗すると、爆発音で殺人鬼に位置がバレる
- **パレット** を倒すと殺人鬼をスタン、**窓** は乗り越えて時間稼ぎ、**ロッカー** に隠れる
- 2回攻撃でダウン → フックへ。フックでは自力脱出に挑戦でき、吊られ続けると脱落
