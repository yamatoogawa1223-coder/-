# 中学英語トレーニング（Android 対応）

中学1〜3年の英語を練習できるアプリです。Android では **①アプリ（APK）として入れる** か **②Chrome からホーム画面に追加する** のどちらでも使えます。

## できること

| モード | 内容 |
| --- | --- |
| 🔤 単語クイズ | 4択で意味をこたえる（英→日／日→英を切りかえ可）。発音も聞ける |
| 🃏 単語カード | タップでめくって覚える。「まだ」にした単語は苦手リストへ |
| 📘 文法クイズ | 空所に入る語をえらぶ。be動詞〜現在完了・関係代名詞・仮定法まで、解説つき |
| 🧩 並べかえ | 日本語に合うように単語をタップして英文を作る |
| 🔁 苦手を復習 | まちがえた問題だけをもう一度出題（正解すると苦手リストから外れる。何度もまちがえた問題は複数回正解が必要） |

- 学年（中1／中2／中3／全学年）を選んで出題
- 連続学習日数・解いた問題数・正答率を記録（端末内に保存）
- ダークモード対応、オフラインで動作
- 収録：単語 200 語、文法 72 問、並べかえ 24 問（`www/data.js` を編集すれば追加できます）

## ① APK をインストールする

1. GitHub のこのリポジトリで **Actions → Android APK** を開く
2. いちばん新しい成功した実行（緑のチェック）を開き、下の **Artifacts** から `chugaku-eigo-apk` をダウンロード
3. zip を開いて出てくる `app-debug.apk` を Android 端末に送ってタップ
4. 「提供元不明のアプリ」のインストールを許可してインストール

Android Studio で `english-app/android` フォルダを開いて ▶ 実行しても入れられます。

発音は端末の「テキスト読み上げ（TTS）」を使います。音が出ないときは、Android の設定 → システム → 言語 → テキスト読み上げ で英語の音声データを入れてください。

## ② ブラウザで使う（ホーム画面に追加）

1. GitHub の **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存
2. Android の Chrome で `https://<ユーザー名>.github.io/<リポジトリ名>/english-app/www/` を開く
3. ホームの「インストール」ボタン、または Chrome のメニュー →「ホーム画面に追加」

## フォルダ構成

```
english-app/
├── www/        アプリ本体（HTML / JS）。PWA としてそのまま動く
│   ├── index.html
│   ├── data.js         単語・文法・並べかえの問題データ
│   ├── manifest.webmanifest, sw.js, icon.*
└── android/    www を WebView で表示する Android アプリ（Java、外部ライブラリなし）
```
