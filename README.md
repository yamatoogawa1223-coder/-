# スーパーピクセルラン

マリオ風の横スクロール・アクションゲームです。HTML ファイル 1 枚で動きます（外部ライブラリなし）。

## 遊び方

`index.html` をブラウザで開くだけ。スマホではタッチボタンが表示されます。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ← → / A D | ◀ ▶ |
| ジャンプ（長押しで高く） | Space / ↑ / Z | A |
| ダッシュ | Shift / X | B |
| ポーズ | P / Esc | — |
| 音のオン・オフ | M | — |

## 内容

- 敵を踏んで倒す（連続で踏むと得点アップ）
- 「?」ブロックからコイン、キノコ（パワーアップで大きくなる）
- 大きい状態ならレンガを壊せる
- カメの甲羅を蹴って敵をまとめて倒す
- 中間ポイント、制限時間、コイン 100 枚で 1UP
- ゴールの旗にタッチしてお城へ入ればクリア

# サミットクライム（Celeste 風）

`celeste.html` をブラウザで開くだけで遊べる、Celeste 風の 1 画面完結型アクションです（HTML 1 枚・外部ライブラリなし）。全 17 ルームを登って山頂をめざします。BGM つき（コード進行はエリアごとに変化、後半ほど厚くなります）。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 / ダッシュの向き | ← → ↑ ↓ / WASD | 十字ボタン |
| ジャンプ（長押しで高く・壁ジャンプ可） | C / Space | ジャンプ |
| ダッシュ（8方向・空中1回） | X / J | ダッシュ |
| 壁をつかんで登る（スタミナ制限） | Z / Shift | 掴む |
| ルームやり直し / 音オン・オフ | R / M | — |

- 着地かクリスタルでダッシュ回復、ダッシュ中に地上でジャンプするとスーパー／ハイパージャンプ
- トゲ、崩れる床、隠れイチゴ（ルーム内で死なずに出口へ運ぶと獲得）
- 死亡回数とクリアタイムを記録
