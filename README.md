# スーパーピクセルラン

マリオ風の横スクロール・アクションゲームです。HTML ファイル 1 枚で動きます（外部ライブラリなし）。

## 遊び方

`index.html` をブラウザで開くだけ。スマホではタッチボタンが表示されます。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ← → / A D | ◀ ▶ |
| ジャンプ（長押しで高く） | Space / ↑ / Z | A |
| ダッシュ | Shift / X | B |
| ポーズ | P / Esc | — |
| 音のオン・オフ | M | — |

## 内容

- 敵を踏んで倒す（連続で踏むと得点アップ）
- 「?」ブロックからコイン、キノコ（パワーアップで大きくなる）
- 大きい状態ならレンガを壊せる
- カメの甲羅を蹴って敵をまとめて倒す
- 中間ポイント、制限時間、コイン 100 枚で 1UP
- ゴールの旗にタッチしてお城へ入ればクリア

# ケツイ・ダンジョン（Undertale 風）

`undertale.html` をブラウザで開くと遊べる、Undertale 風の RPG です（1 ファイル・外部ライブラリなし）。

- 探索: 矢印/WASD で移動、Z で話す・セーブ（星）、X 長押しでダッシュ
- 戦闘: たたかう / こうどう / どうぐ / みのがす
  - 「こうどう」で相手の気持ちを動かすと、みのがせるようになる（名前が ★ に）
  - 敵のターンは弾幕よけ。矢印で赤いハートを動かし、X 長押しでゆっくり移動
  - 「たたかう」はタイミングバー（中央ほど大ダメージ）
- 敵は 2 体（ゲコロン・ボーンズ）。誰も倒さないと特別なエンディング
