# スーパーピクセルラン

マリオ風の横スクロール・アクションゲームです。HTML ファイル 1 枚で動きます（外部ライブラリなし）。

## 遊び方

`index.html` をブラウザで開くだけ。スマホではタッチボタンが表示されます。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ← → / A D | ◀ ▶ |
| ジャンプ（長押しで高く） | Space / ↑ / Z | A |
| ダッシュ | Shift / X | B |
| ポーズ | P / Esc | — |
| 音のオン・オフ | M | — |

## 内容

- 敵を踏んで倒す（連続で踏むと得点アップ）
- 「?」ブロックからコイン、キノコ（パワーアップで大きくなる）
- 大きい状態ならレンガを壊せる
- カメの甲羅を蹴って敵をまとめて倒す
- 中間ポイント、制限時間、コイン 100 枚で 1UP
- ゴールの旗にタッチしてお城へ入ればクリア

# ゾンビサバイバー（ダダサバイバー風）

`survivor/index.html` をブラウザで開くだけで遊べる、ダダサバイバー風のサバイバルアクションです（外部ライブラリなし）。

- 攻撃は自動。移動して敵を避けながら経験値ジェムを集める
- レベルアップごとに 3 つのスキルから 1 つを選ぶ（武器 6 種・強化 6 種、各 Lv5 まで）
- 60 秒ごとにエリート、定期的に包囲ウェーブ、5:00 にボス「ゾンビキング」が出現。倒せばクリア
- ベスト記録はブラウザに保存

| 操作 | PC | スマホ |
| --- | --- | --- |
| 移動 | WASD / 矢印キー / マウスでドラッグ | 画面をスワイプ（どこでも） |
| スキル選択 | クリック / 1・2・3 キー | タップ |
| ポーズ | P / Esc / 右上のボタン | 右上のボタン |
| 音のオン・オフ | M | — |
