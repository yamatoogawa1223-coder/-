# スーパーピクセルラン

マリオ風の横スクロール・アクションゲームです。HTML ファイル 1 枚で動きます（外部ライブラリなし）。

## 遊び方

`index.html` をブラウザで開くだけ。スマホではタッチボタンが表示されます。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | ← → / A D | ◀ ▶ |
| ジャンプ（長押しで高く） | Space / ↑ / Z | A |
| ダッシュ | Shift / X | B |
| ポーズ | P / Esc | — |
| 音のオン・オフ | M | — |

## 内容

- 敵を踏んで倒す（連続で踏むと得点アップ）
- 「?」ブロックからコイン、キノコ（パワーアップで大きくなる）
- 大きい状態ならレンガを壊せる
- カメの甲羅を蹴って敵をまとめて倒す
- 中間ポイント、制限時間、コイン 100 枚で 1UP
- ゴールの旗にタッチしてお城へ入ればクリア

# ネコ大戦争（nyanko.html）

「にゃんこ大戦争」風のタワーバトルです。`nyanko.html` をブラウザで開くだけで遊べます（スマホ対応）。

- 下のボタンでネコを出撃（お金を消費、再使用までクールダウンあり）
- お金は時間で増加。「お財布」を強化すると上限と増加速度がアップ
- 一定時間ごとに「ネコキャノン」で敵をまとめて攻撃
- ダメージを受けるとノックバック。敵基地を壊せばクリア（全3ステージ）

| 操作 | キー / タップ |
| --- | --- |
| ネコ出撃 | 1〜5 / 下のボタン |
| お財布強化 | Q |
| 大砲 | Space |
| 画面スクロール | ← → / ドラッグ |
| ポーズ・2倍速・音 | P・S・M / 右上 |
